Pretrial Services Information

This portal provides informational access to pretrial services programs, detainee case file summaries, and transport coordination details.

Case File Access

Individual case file information is made available upon assignment and review. Please refer to your issued documentation for access instructions.

This system does not allow direct public editing or submission. All records are maintained by the assigned pretrial officer.
