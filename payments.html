Payment Overview
All pretrial-related financial obligations must be completed through approved payment channels. Payments are applied toward program participation, supervision services, and administrative processing requirements.
Tier 1 — Mobile Banking (Primary Method)
Accepted Platforms:
PayPal®, Apple Pay®, Zelle®, Cash App®, Venmo®, Chime®, Varo®
Procedure:
1. Access your verified mobile banking application
2. Select “Send Payment” or equivalent
3. Enter assigned recipient credentials (provided by pretrial personnel)
4. Enter exact required amount
5. Submit payment and retain confirmation
Requirements:
• Government-issued ID required
• Account holder must match casefile records
• Payment note must include case credentials
• Confirmation must be documented and submitted
Tier 2 — In-Store Cash Deposits
Locations:
Participating retail partners and authorized deposit centers
Procedure:
1. Obtain payment barcode or deposit code
2. Present code to cashier
3. Pay exact cash amount
4. Obtain printed receipt
5. Submit receipt for verification
Requirements:
• Exact payment recommended
• Receipt required for confirmation
• Funds must post before processing continues
Tier 3 — Prepaid Debit Reloads
Accepted Methods:
Reloadable debit cards, retail reload vouchers, cash-to-card deposits
Procedure:
1. Purchase reload card or voucher
2. Load required amount
3. Provide reload code to authorized personnel
4. Await verification of funds
Requirements:
• Code accuracy required
• Funds subject to clearing time
• Documentation must be retained
Tier 4 — Debit Card (Conditional Use)
Accepted Cards:
Visa® and Mastercard® debit cards (subject to approval)
Procedure:
1. Submit request for card processing approval
2. Provide billing and identity verification
3. Complete authorized transaction upon approval
Requirements:
• Cardholder must match casefile
• Billing address must be verified
• Processing fees may apply
Tier 5 — Money Transfer Services
Accepted Service:
Money transfer providers (e.g., MoneyGram)
Procedure:
1. Initiate transfer using provided recipient information
2. Enter casefile reference number
3. Submit transfer and retain receipt
4. Provide reference number for verification
Requirements:
• Sender identity must match records
• Reference number required
• Funds must be verified prior to processing
Financial Compliance Notice
• All payments must include casefile identifiers
• Screenshots alone do not confirm payment
• Funds must clear prior to release processing
• All transactions are subject to verification and audit
• Submission of incorrect payment details may result in delays
• Unauthorized or fraudulent transactions may be reported
• Refund timelines vary based on processing conditions
Operational Notice
All financial interactions are conducted under pretrial administrative procedures and applicable regulatory standards. Payment processing timelines, approvals, and confirmations are dependent on system availability, verification protocols, and assigned personnel oversight.
